Működési feltételek

A SUP Vállalatirányítási Rendszer a kliens-szerver architektúrából következően alapvetően hálózati működési környezetre van tervezve, azonban működtethető egygépes környezetben is. Lehetőség van Microsoft Windows Terminál Szerver (RDP) vagy Citrix környezetben történő üzemeltetésre is.

Hardver és szoftver követelmények

A szerver teljesítményét és memória kapacitását a feldolgozandó adatmennyiséggel és a várható munkahelyek számával összhangban kell meghatározni.

🖥️

Szerver oldali hardver

  • Közepes Linux szerver: Intel® Core™ i7 vagy jobb, 4 GB+ RAM, 500 GB merevlemez, szünetmentes tápegység
  • Erősebb Linux szerver: Intel Xeon processzor, 4 GB+ RAM, 3×500 GB RAID5 merevlemez, mentést biztosító eszköz, szünetmentes tápegység
  • Windows szerver: Intel Xeon kategóriájú processzor, 8 GB+ RAM, 3×500 GB HDD (RAID), szünetmentes tápegység
  • Ha Windows az operációs rendszer, az ajánlotthoz képest legalább 4 GB extra RAM szükséges
⚙️

Szerver oldali szoftver

  • Linux: Ajánlott disztribúció: Debian vagy Ubuntu. File szerver modulként Samba szükséges. A Firebird SQL adatbázis-szerver a disztribúció repozitorijából vagy Docker.CE környezetből telepíthető.
  • Windows Szerver: Windows 2008/2008R2-től Windows 2019 DataCenter-ig bármi megfelelő
  • Windows Desktop (kis cégek esetén): Windows 10 Professional
  • Mac OS X: A Firebird SQL szerver támogatja, de SUP-pal való gyakorlati megvalósításról nincs tudomásunk
💻

Kliens oldali hardver

  • Intel® Core™ i3 vagy jobb kategóriájú számítógép
  • Legalább 4 GB RAM (további alkalmazásoktól függően)
  • 500 MB szabad merevlemez kapacitás
  • 1024×768 képpont felbontásra beállított monitor
🪟

Kliens oldali szoftver

  • Operációs rendszer: Windows 10 Professional vagy Ultimate változata
  • A Windows 95/98/Me/Vista/2000/XP és egyéb Home vagy Embedded (IoT) változatok nem alkalmasak!
  • Szükséges a Firebird SQL adatbázismotor kliensének telepítése
  • Ajánlott a Windows legutolsó Service Pack telepítése
